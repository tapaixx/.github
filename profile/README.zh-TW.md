### `01 / 我們的理念`

我們致力於讓複雜系統更容易觀察、重複工作可以程式化，讓開發者每天使用的工具更穩定、更順手。

**清晰、可靠、持續探索。** 我們關注 AI 程式開發工作流程、API 基礎設施、自動化，以及 Apple 平台上的實用產品。

### `02 / 精選專案`

| 專案 | 簡介 | 技術領域 |
| :--- | :--- | :--- |
| ⚡ **[Codex Header Rewrite](https://github.com/tapaixx/codex-header-rewrite)** | CLIProxyAPI 原生外掛，提供依憑證設定的請求標頭規則、請求診斷與受控檢視功能。 | Go · API 基礎設施 |
| ◉ **[Codex Window Reset](https://github.com/tapaixx/codex-window-reset)** | 管理 Codex 帳號的使用時段、配額、健康檢查與執行狀態。 | Go · 自動化 |

| ◇ **[Private Signer for iOS](https://github.com/tapaixx/private-signer-ios)** | 適用於 iOS/iPadOS 簽署工作流程的 Swift SDK，支援專案探索與簽署工作。 | Swift · SDK |
